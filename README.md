# Formularios Mercado Cheque

Formulario online para que los clientes completen el **Informe comercial, ventas y deudas** y la **Manifestación de bienes**, y descarguen cada uno en PDF A4.

- Link público: https://marketingmercadocheque.github.io/formularios/
- Es una sola página estática (`index.html`). No hay servidor ni base de datos: lo que completa el cliente queda solo en su navegador (se borra solo a los 30 días sin uso) y nada se envía a ningún lado.
- Versión sin marca: agregar `?sin-marca` al final del link.
- Para actualizarlo, reemplazá `index.html` y hacé commit en `main`: GitHub Pages lo publica en uno o dos minutos.
